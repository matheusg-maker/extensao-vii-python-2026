Apresentação do projeto

O presente trabalho faz parte do Projeto de Extensão VII, desenvolvido no âmbito da UNIFIL, e tem como proposta a criação e disponibilização de um curso introdutório de Programação Básica em Python.

O projeto foi elaborado com o objetivo de compartilhar conhecimentos básicos de programação, proporcionando aos participantes uma primeira experiência com a lógica computacional e com a linguagem Python.

O conteúdo foi organizado de maneira progressiva, começando pelos conceitos iniciais de programação e avançando até a construção de um pequeno projeto prático: uma calculadora interativa.

Para facilitar o acesso e o acompanhamento das aulas, os conteúdos foram disponibilizados em vídeos no YouTube, utilizando o Google Colab como ambiente para desenvolver e executar os exemplos de programação.

Objetivos do projeto

O principal objetivo é introduzir os fundamentos da programação por meio da linguagem Python, tornando o aprendizado acessível para pessoas que ainda não possuem experiência na área.

  • Apresentar os conceitos fundamentais da programação.
  • Introduzir a linguagem Python e sua utilização.
  • Ensinar o uso do ambiente Google Colab.
  • Demonstrar a utilização de variáveis e tipos de dados.
  • Trabalhar operações matemáticas e entrada de dados.
  • Apresentar estruturas condicionais e de repetição.
  • Desenvolver conhecimentos básicos sobre listas.
  • Aplicar os conhecimentos em um projeto prático final.

Metodologia

O curso foi estruturado em uma introdução e dez aulas sequenciais, com explicações teóricas e demonstrações práticas. A organização progressiva permite que os participantes acompanhem os conteúdos desde os primeiros comandos até a construção de um programa funcional.

Durante as aulas, são utilizados exemplos de código desenvolvidos em Python no Google Colab, permitindo visualizar a execução dos comandos e compreender sua aplicação.

Projeto final

Como atividade de encerramento, o curso apresenta a construção de uma calculadora interativa em Python. O programa solicita o nome do usuário e dois números, realiza operações matemáticas e apresenta os resultados.

Essa atividade permite aplicar conhecimentos trabalhados durante o curso, como variáveis, entrada de dados, conversão de tipos e operações matemáticas.
