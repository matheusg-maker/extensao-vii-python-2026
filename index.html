Sobre o projeto

Este site apresenta o projeto de extensão Curso de Programação Básica em Python, desenvolvido com o objetivo de introduzir conceitos fundamentais de programação para pessoas iniciantes.

O curso utiliza a linguagem Python e o ambiente Google Colab, com explicações progressivas, exemplos práticos e atividades que facilitam o aprendizado.

O conteúdo está organizado em uma introdução e dez aulas, disponibilizadas em vídeo no YouTube.
