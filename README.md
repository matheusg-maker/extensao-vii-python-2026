
# Projeto de Extensão VII — Curso de Programação Básica em Python

## Apresentação

Este projeto apresenta um curso introdutório de programação utilizando a linguagem Python. O conteúdo foi desenvolvido para pessoas que desejam conhecer os fundamentos da programação e dar os primeiros passos na criação de programas.

As aulas utilizam o Google Colab como ambiente de desenvolvimento e estão disponíveis gratuitamente no YouTube.

## Objetivo

Introduzir conceitos fundamentais de programação e desenvolver conhecimentos básicos sobre a linguagem Python por meio de explicações e exemplos práticos.

## Conteúdo do curso

- Introdução — Apresentação do curso
- Aula 01 — Introdução à programação
- Aula 02 — Conhecendo o Google Colab
- Aula 03 — Primeiro programa, print() e comentários
- Aula 04 — Variáveis
- Aula 05 — Tipos de dados
- Aula 06 — Entrada de dados com input()
- Aula 07 — Operadores matemáticos
- Aula 08 — Estruturas condicionais
- Aula 09 — Repetições e listas
- Aula 10 — Projeto final: calculadora interativa

## Tecnologias e ferramentas

- Python
- Google Colab
- YouTube
- GitHub Pages
- HTML e CSS

## Acesso ao curso

Os vídeos estão organizados no site do projeto, com acesso direto a cada aula.
